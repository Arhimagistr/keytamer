## 1. Контекст и цели задачи
1. **Пауза и продолжение записи:**
   - Предоставить возможность приостанавливать запись аудио по Пробелу во время речи, не сбрасывая накопленный фрагмент и не записывая лишнюю тишину/фоновый шум.
   - Возобновлять запись по повторному нажатию Пробела.
2. **Настраиваемая клавиша отмены записи:**
   - Реализовать отмену текущей записи по одиночному клику Command (`⌘`), чтобы отменять надиктованный текст большим пальцем без необходимости тянуться к Escape.
   - Сохранить поддержку Escape.
3. **Повторная вставка последней расшифровки по Double-Tap:**
   - Внедрить возможность вставлять последнюю надиктованную фразу двойным нажатием Option (`2× ⌥`).
   - Реализовать арбитраж задержкой (250 мс), предотвращающий ложный запуск диктовки при первом тапе ⌥ перед выполнением вставки.
4. **Соблюдение регламентов разработки:**
   - Doc-First (`doc-first-development`): фиксация ADR-011 в `HISTORY.md` до написания функционального кода.
   - TDD (`tdd-workflow`): разработка через тест Test 9 в `Tests/RemediationTests.swift` (Red-Green).
   - YAGNI (`yagni-development`): лаконичная реализация без избыточных обёрток.

## 2. Реализованные изменения по компонентам

### 1. Ядро захвата звука (`AudioRecorder.swift`)
- Добавлены потокобезопасные методы `pause()` и `resume()`, а также свойство `isPaused`.
- В колбэке захвата CoreAudio `captureOutput`: при активной паузе сэмплы отбрасываются (не сохраняются в `samples`), а уровень сигнала RMS передаётся как `0`, предотвращая ложные колебания волны от посторонних шумов.
- При вызове `start()`, `stop()` и `discard()` состояние паузы детерминированно сбрасывается.

### 2. Оркестратор диктовки (`VoiceController.swift`)
- Добавлен метод `togglePause()` и свойство `isPaused`.
- При переключении паузы:
  - Рекордер переводится в режим паузы/возобновления.
  - Воспроизводится звуковой щелчок (cue).
  - Индикатор `VoiceIndicator.shared.setPaused(...)` переключается в состояние паузы.
- При финализации записи `end()` или отмене `cancel()` статус паузы гарантированно снимается.

### 3. Индикатор записи (`VoiceIndicator.swift`)
- Добавлен метод `setPaused(_ paused: Bool)`:
  - При паузе волна останавливается (`wave.stop()`), а текст меняется на локализованное сообщение «Пауза».
  - При возобновлении волна запускается заново (`wave.start(shimmer: false)`), а текст возвращается в «Слушаю…».

### 4. Перехватчик событий клавиатуры (`EventTap.swift`)
- **Пауза по Пробелу:** В `handleKeyDown` при активной записи `isRecording` нажатие Пробела (keyCode 49) без модификаторов перехватывается, проглатывается (`swallowDown`) и вызывает `VoiceController.shared.togglePause()`.
- **Отмена по Command:** В `handleFlags` при активной записи отслеживается solo tap клавиши Command (keyCode 54/55); при нажатии вызывается `VoiceController.shared.cancel()`.
- **Вставка 2× Option:** В `handleFlags` реализован детектор двойного нажатия Option в окне 280 мс. При совпадении вызывается `handlePasteDictationHotkey()`.
- **Арбитраж задержки:** При одиночном тапе Option для запуска диктовки вызов `toggleVoice` откладывается на 250 мс. Если за этот интервал поступает второй тап Option, таймер диктовки отменяется и выполняется вставка последней расшифровки.

### 5. Настройки и интерфейс (`AppSettings.swift`, `SettingsWindow.swift`, `L10n.swift`)
- В `AppSettings` добавлены параметры:
  - `voicePauseEnabled` (по умолчанию `true`) и `voicePauseKeyCode` (`49` = Space).
  - `voiceCancelByCommand` (по умолчанию `true`).
  - `pasteDictationTrigger` ("doubletap" / "hotkey"), `pasteDictationDoubleTap`, `pasteDictationDoubleTapModifier`.
- В `SettingsWindow` в группу настроек диктовки добавлены тумблеры управления паузой, отменой по Command и выпадающий селектор режима вставки последней диктовки.
- В `L10n.swift` добавлены локализованные строки для русского и английского языков.
