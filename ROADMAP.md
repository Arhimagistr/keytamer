# Keytamer — Strategic Roadmap

> **Current Phase:** Phase 3 — Ребрендинг и публичный релиз Keytamer

## Phases Overview
- [x] **Phase 1: Локализация и устранение корневой причины обрыва диктовки**
  - Анализ работы `VoiceController.deliver` и `TextReplacer.typeUnicode`.
  - Выявление дропа синтетических `CGEvent` пакетов в веб-/Electron-приложениях.
- [x] **Phase 2: Разработка механизма безопасного буфера и UI**
  - Реализация `TextReplacer.pasteViaClipboard` с сохранением/восстановлением типов буфера обмена.
  - Добавление `voiceClipboardPaste` и `voiceClipboardThreshold` в `AppSettings.swift`.
  - Встраивание тумблера и селектора порога в `SettingsWindow.swift` и локализаций в `L10n.swift`.
  - Подключение к `VoiceController.swift` и `Engine.swift` (хоткей последней диктовки).
- [x] **Phase 3: Ребрендинг в Keytamer и подготовка репозитория**
  - Полный переход на идентификатор `com.keytamer.tamer`.
  - Настройка сборочных скриптов `build-app.sh` и `install-local.sh` под `Keytamer.app`.
  - Реструктуризация истории коммитов Git с чистой цепочкой изменений.
  - Публикация репозитория на GitHub.
- [x] **Phase 4: Ремедиация дефектов totals-critic и TDD верификация**
  - [x] Фикс сброса флага `voiceModArmed` при удержании оверрайда (`EventTap.swift`)
  - [x] Изоляция путей `Application Support/Keytamer` и взаимная проверка `singleton.lock` с Keyboop
  - [x] Устранение `TransientType` при восстановлении буфера пользователя (`TextReplacer.swift`)
  - [x] Сериализация `pasteViaClipboard` через `synthQueue`
  - [x] TDD регрессионный сьют и приемочный аудит work-verifier
